## Objective and Architecture

The objective is a native Swift implementation that emits byte-identical frames and terminal streams for the same input, configuration, canvas, seed, and completion boundary as Rust. The module direction is:

```text
TTFXCLI -> TTFXCore
TTFXEffects -> TTFXCore
TTFXCoreTests -> TTFXCore
TTFXEffectsTests -> TTFXEffects -> TTFXCore
```

The runtime pipeline is:

```text
EffectEngine
  -> RuntimeEffect.scheduleTick
  -> AnimationRuntime.update
  -> paths and scenes
  -> typed RuntimeActions and events
  -> collision-aware render
  -> Frame
```

The architecture deliberately centralizes ordering, scheduling, random draws, motion, scenes, and completion. Effect-local substitutes would duplicate load-bearing behavior and make parity claims unreliable.

## Known Risks and Gotchas

- **Untracked identity:** most Swift/OpenSpec artifacts are untracked. Filesystem inventories and direct command receipts cannot substitute for Git-backed changed-file identity.
- **Serialized Rust tests:** independent parity tests spawn Cargo. Parallel live Rust suites previously timed out; retain `.serialized` and avoid concurrent invocation.
- **ANSI input limitation:** `InputText` currently carries scalars/coordinates but not parsed preexisting ANSI colors. Core scene interpolation supports preexisting colors, but Print and Slide do not claim unavailable colored-input/CLI modes.
- **Size exception:** the accepted delivery is one logical PR under a maintainer-approved `size:exception`, despite high review risk and earlier chained-PR language.
- **Runtime authority:** status `complete` is terminal. Further runtime-bearing work requires documented reset/rescope, fresh acquire, bounded execution, and settle.
- **Reset scope:** repeated reset/rescope was authorized for this change only. State the narrow reason each time; never treat it as an implicit retry loop.
- **Fixture pinning:** generator `--check` uses current Git HEAD as Rust revision. A different HEAD intentionally makes the corpus stale until deliberate regeneration and evidence reconciliation.
- **Evidence placement:** passing runtime metadata is insufficient when the active apply document omits the exact receipt the gate requires.
- **Quirk provenance:** the effect spec requires every `QUIRK(...)` marker to reference `plan.md` or `ordering-inventory.md`, not only a Rust source range.
